# Projeto RIG - Vértice

Landing page institucional da Vértice (Relações Institucionais e Governamentais), construída com HTML, CSS e JavaScript puros.

## Estrutura

- `index.html`: estrutura da página
- `style.css`: estilos, temas claro/escuro e responsividade
- `script.js`: interações (tema, menu mobile, animações, formulário)
- `assets/`: logos, favicon e recursos visuais

## Como executar localmente

Na raiz do projeto:

```bash
python -m http.server 8000
```

Acesse:

- `http://localhost:8000`

## Publicação

Este projeto é estático e pode ser publicado em qualquer hosting de arquivos estáticos (GitHub Pages, Netlify, Vercel, Cloudflare Pages, etc.).

Fluxo usado neste repositório:

1. Commit das alterações na branch `main`
2. Push para `origin/main`

Se o ambiente de produção estiver configurado para deploy automático a partir da `main`, a publicação acontece após o push.
